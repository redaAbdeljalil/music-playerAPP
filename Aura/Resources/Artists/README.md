# Artist photos

Drop a photo in here named exactly `artist_<slug>.jpg` (or `.jpeg` / `.png` / `.heic`) and it
replaces the generated placeholder automatically — no code changes, no rebuild logic to touch.

See `../MEDIA_CHECKLIST.md` for the exact filename expected for each artist.

Until a photo is added, that artist's portrait areas (Home, Artist page header, Search results)
render a generated abstract gradient tinted with the artist's signature color instead of a
broken image.
